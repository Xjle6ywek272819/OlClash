# Privacy Policy

_Last updated: 2026-09-16_

OlcLash is an open-source Android VPN client. The project does not operate an account service, VPN service, analytics service, advertising network, or telemetry backend.

## Local data

Imported profiles, subscription URLs, routing preferences, per-app choices, connection settings, and diagnostic logs are stored on the device. Android backup or device-vendor services may handle them according to their own settings and policies.

## Network data

OlcLash communicates with services selected or configured by the user: subscription providers, selected Mihomo proxies, OLCWave/olcRTC signaling and TURN infrastructure, configured DNS resolvers and geo-data mirrors, and GitHub for release checks or downloads. Those independent operators have their own logging and privacy practices.

VPN operation necessarily processes destination addresses, DNS requests, and traffic metadata locally. The project does not intentionally upload them to an OlcLash-controlled server.

## Logs

Logs may contain IP addresses, hostnames, endpoints, and device details. Before reporting a problem, remove subscription URLs and bodies, credentials, room IDs, tokens, HWIDs, device identifiers, and other sensitive data.

## Security and contact

No transmission or storage method is completely secure. Install releases from the official repository and keep credentials private. For questions, open a redacted GitHub issue. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
